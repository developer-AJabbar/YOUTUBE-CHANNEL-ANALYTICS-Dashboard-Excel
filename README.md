📊 YouTube Analytics Dashboard in Microsoft Excel
Overview

The YouTube Analytics Dashboard is an interactive Microsoft Excel project designed to transform raw YouTube channel data into meaningful business insights. Built using Pivot Tables, Pivot Charts, Slicers, Excel Formulas, and KPI Cards, this dashboard allows users to monitor channel performance, analyze audience engagement, track subscriber growth, evaluate revenue trends, and make data-driven decisions. It is an ideal solution for content creators, digital marketers, business analysts, and marketing agencies seeking a simple yet powerful analytics tool.

Features

This dashboard includes an interactive user interface with dynamic filtering through Slicers, making it easy to explore data from different perspectives. It provides real-time KPI summaries, subscriber growth analysis, views analysis, watch time tracking, estimated revenue monitoring, engagement metrics, and monthly performance trends. The dashboard is designed with a clean and professional layout, ensuring an intuitive user experience while delivering valuable analytical insights.

Key Metrics

The dashboard highlights essential performance indicators, including Total Subscribers, Total Views, Total Videos, Estimated Revenue, Average Revenue per Video, Monthly Performance, and Growth Trends. These metrics enable users to quickly evaluate channel performance and identify opportunities for growth.

Tools & Skills Used

This project was developed using Microsoft Excel and demonstrates proficiency in Pivot Tables, Pivot Charts, Slicers, Excel Formulas, Dashboard Design, Data Cleaning, Data Analysis, KPI Development, and Business Intelligence techniques. It showcases the practical application of Excel as a powerful business analytics and reporting tool.

Project Workflow

The project follows a structured analytics workflow, beginning with data collection, followed by data cleaning and data preparation to ensure accuracy and consistency. After preparing the dataset, Pivot Tables and Pivot Charts were created to summarize the data, while KPI calculations were developed to measure key business metrics. Finally, an interactive dashboard was designed with slicers and visualizations to support efficient performance analysis and decision-making.

Business Value

This dashboard enables YouTube creators, digital marketers, content strategists, marketing agencies, and business analysts to monitor channel performance efficiently and uncover actionable insights. By presenting complex data through interactive visualizations and key performance indicators, the dashboard supports informed business decisions, performance optimization, and long-term growth strategies.
